# Security policy

If you discover a vulnerability in the **documentation examples** or **Ansible roles** of this repository, please email the Nowo Tech maintainers via the contact channels listed on [nowo.tech](https://nowo.tech) or open a **private** security advisory on GitHub.

Please do **not** open a public issue that includes exploit details for live deployments.

This project hardens hosts; misuse against systems you do not own is prohibited.
